# etch-a-sketch

A browser-based sketch pad built using HTML, CSS and JavaScript 

## Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript

## Features

- Dynamically generated grid of squares
- Random RGB colours on mouse hover
- Resizable grid with a maximum size of 100 × 100
- Clear button to reset the sketch pad

## What I Learned

- Dynamically creating and manipulating DOM elements
- Using Flexbox to create a grid layout
- Event delegation and mouse events
- Handling user input and validating values
- Working with random RGB colours
